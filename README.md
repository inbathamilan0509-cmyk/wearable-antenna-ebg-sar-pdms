# 📡 Biocompatible Wearable Antenna Using EBG Structure for Low SAR Application

🏆 **Best Project Award — COMSPRO 2026, Dept. of ECE, SRMIST**
🌏 **Presented at 17th International Conference on Science & Innovative Engineering 2026**
🏛️ **Manipal University College, Malaysia**

---

## 📌 Overview

This project presents the design and simulation of a **biocompatible wearable 
microstrip patch antenna** operating at **2.45 GHz ISM band**, integrated with 
a **4×4 Electromagnetic Band Gap (EBG) array** to minimize Specific Absorption 
Rate (SAR) for safe human body applications.

---

## ❓ Problem Statement

When wearable antennas are placed near the human body:
- Electromagnetic energy gets absorbed by body tissue
- SAR values increase dangerously close to IEEE limits (1.6 W/kg)
- Traditional substrates like FR4 are not flexible or biocompatible

---

## ✅ Our Solution

- Used **PDMS (Polydimethylsiloxane)** — a flexible, biocompatible substrate
- Integrated a **4×4 EBG array** beneath the antenna
- EBG structure blocks surface waves and reduces backward radiation
- Result: SAR reduced by **49%** while maintaining antenna performance

---

## 📊 Key Results

| Parameter | Without EBG | With EBG |
|---|---|---|
| SAR Value | 1.387 W/kg | 0.708 W/kg |
| Return Loss | < -10 dB | < -10 dB |
| Resonant Frequency | 2.45 GHz | 2.45 GHz |
| Gain | 4.0 dBi | 4.1 dBi |
| IEEE Safety Limit | 1.6 W/kg | ✅ Compliant |

---

## 🛠️ Tools & Technologies

- **Simulation:** Ansys HFSS
- **Substrate:** PDMS (εr = 2.7, tanδ = 0.02)
- **Structure:** 4×4 EBG Mushroom Array
- **Phantom Model:** 3-layer human tissue (Skin + Fat + Muscle)
- **Operating Frequency:** 2.45 GHz ISM Band
